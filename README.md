# SaddlepointExpansions for MATLAB

Saddlepoint expansions of any order for tail probabilities and densities of random vectors,
from the cumulant generating function alone. This is the MATLAB counterpart of the Julia package
[SaddlepointExpansions.jl](https://github.com/s-broda/SaddlepointExpansions.jl) and implements the
expansions of Broda and Kan, "Uniform saddlepoint expansions for multivariate tail
probabilities": the orthant probability `P(X >= x)` of a random vector in any
dimension, its density, and the joint density and distribution function of a vector of ratios
`(X_1/Y_1, ..., X_d/Y_d)`, with the
univariate expansions of Daniels and of Hauschildt and Robinson as the one-dimensional case; and
those of Bao, Broda and Kan, "Inversion formulas and saddlepoint expansions for Studentized means",
for the density, distribution function and quantiles of `X/sqrt(Y)` (`studentized_density`,
`studentized_tailprob`, `studentized_quantile`). The expansion of order `M` has relative error
`O(n^-M)`; saddlepoints with negative components are handled by inclusion-exclusion.

Version 0.2.2 (November 2026), the version of the Julia and Python packages with the same
functions.

The cumulant generating function is supplied as an ordinary MATLAB function. All its derivatives
are generated by Taylor-mode automatic differentiation (the class `tps`, truncated multivariate
power series with overloaded arithmetic and elementary functions), directly in the whitened
coordinates in which the expansions are evaluated.

```matlab
spx_setup                                   % adds the package and its engine to the path

% X = (U0 + U1, U0 + U2), U_i independent unit exponentials; the mean of n = 5 observations
K = CGF(@(t) -log(1 - t(1)) - log(1 - t(2)) - log(1 - t(1) - t(2)), 2, ...
        'domain', @(t) t(1) < 1 && t(2) < 1 && t(1) + t(2) < 1);
Kn = sample_mean(K, 5);

r = tailprob(Kn, [3 3], 'order', 4);  r.F   % P(mean1 >= 3, mean2 >= 3), orders 1 to 4; exact 0.02215196
r = density(Kn, [3 3], 'order', 4);   r.f   % the joint density
r = tailprob(Kn, [3 3], 'lower', true);     % P(mean1 <= 3, mean2 <= 3)
```

## Functions

| | |
|---|---|
| `CGF(fun, d, 'domain', pred)` | a cumulant generating function `fun(t)`, `t` a `d x 1` vector |
| `tailprob(K, x, 'order', M, 'lower', tf, 'signs', s)` | orthant probabilities of orders `1..M` (`r.F`), saddlepoint `r.tau`, `r.status`, `r.info` |
| `density(K, x, 'order', M)` | densities of orders `1..M` (`r.f`) |
| `ratio_density(K, r0, 'order', M)` | joint density of `R = (X_1/Y_1, ..., X_d/Y_d)` at `r0`, `d = numel(r0)`, `Y_j > 0`; `K` is the cgf of `(X, Y)` (dimension `2d`) or, for a common denominator, of `(X_1, ..., X_d, Y)` (dimension `d + 1`) |
| `ratio_tailprob(K, r0, 'order', M, 'lower', tf, 'signs', s)` | `P(R >= r0)`, `P(R <= r0)` or a mixed corner |
| `studentized_density(K, q, 'order', M)` | density of the Studentized mean `Q = X/sqrt(Y)`, `Y > 0`, at `q`; `K` is the joint cgf of `(X, Y)` (dimension 2) |
| `studentized_tailprob(K, q, 'order', M, 'lower', tf)` | `P(Q >= q)` or `P(Q <= q)`; `r.F`, `r.info.Fp` (every half-order) |
| `studentized_quantile(K, p, 'order', M)` | the `q` with `P(Q <= q) = p` under the expansion |
| `studentized_saddlepoint(K, q)`, `studentized_locus(K, s, tguess)` | the saddlepoint `(s, t, v)` and the saddlepoint locus |
| `saddlepoint(K, x)` | the saddlepoint `K'(tau) = x` |
| `derivatives(K, t, N)` | all derivatives of orders `<= N` at `t` (`D.nu`, `D.value`) |
| `reflect`, `marginal`, `linear_combination`, `sample_mean`, `shift`, `K1 + K2` | transformations |
| `normal_cgf`, `gamma_cgf`, `ncx2_cgf`, `exponential_sums_cgf`, `quadratic_forms_cgf`, `wishart_diag_cgf`, `common_component_cgf`, `uniform_cgf` | library of cumulant generating functions |
| `sinhc`, `sincu` | `sinh(x)/x` and `sin(x)/x` with the removable singularity handled |
| `tps` | the Taylor class (`tps.vars(k, N)`, `coef(p, nu)`) |

Further name-value pairs of `tailprob` and `density` are passed to the engine: `nG`, `qtol`,
`logscale` (bivariate), `method`, `nqmc` (four or more dimensions), and so on.

`fun` must be written with operations the Taylor class supports: `+ - .* ./ .^` and `*` with
constant matrices, `sum`, `prod`, indexing `t(j)`, `exp`, `log`, `log1p`, `expm1`, `sqrt`, `sin`,
`cos`, `tan`, `sinh`, `cosh`, `tanh`, `atan`, `abs`, `sinhc`, `sincu`. Outside the domain it may
raise an error with identifier `tps:domain` (`log` and `sqrt` of a nonpositive number do so) or
return a non-finite value; when the formula is finite outside the domain (`1/(1 - t)` for `t > 1`)
give the `'domain'` predicate. Comparisons on series compare their constant terms, so code with
tests on the argument works. Determinants and inverses of matrices that depend on `t` can be
written as a Cholesky factorization in plain arithmetic (see `tests/test_spx.m`), or, for
quadratic forms in normal vectors, `quadratic_forms_cgf` computes the derivatives in closed form
by the trace recursion of the paper, which is much faster for large matrices.

Several ratios, for example the sample autocorrelations at lags 1 and 2 of 50 observations:

```matlab
N = 50; M = eye(N) - ones(N)/N; A = @(j) (diag(ones(N-j,1), j) + diag(ones(N-j,1), -j))/2;
K = quadratic_forms_cgf({M*A(1)*M, M*A(2)*M, M});   % common denominator z'Mz
ratio_density(K, [-1 -1]/sqrt(N), 'order', 5).f
ratio_tailprob(K, [-1 -1]/sqrt(N), 'order', 5, 'lower', true).F
```

A Studentized mean, for example the noncentral t: with `X ~ N(mu, 1)` and `Y ~ chi^2_nu/nu`
independent and `n` pairs, `Xbar/sqrt(Ybar) = T/sqrt(n)` with `T` noncentral t (`n*nu` degrees of
freedom, noncentrality `sqrt(n)*mu`):

```matlab
mu = 1; nu = 3; n = 16;
K = sample_mean(CGF(@(t) mu*t(1) + t(1)^2/2 - nu/2*log(1 - 2*t(2)/nu), 2, 'domain', @(t) t(2) < nu/2), n);
studentized_tailprob(K, 6/sqrt(n), 'order', 3, 'lower', true).F   % P(T <= 6); exact 0.9539798478
studentized_density(K, 6/sqrt(n), 'order', 3).f/sqrt(n)           % density of T at 6
studentized_quantile(K, 0.05, 'order', 3).q*sqrt(n)                % the 5% quantile of T
```

The full manual is `doc/manual.pdf`.

## Folders

* the top folder: `CGF`, `tps`, the library and `spx_setup`;
* `engine/`: the low-level programs of the paper (`spa_saddle`, `spa_uni`, `spa_bi`,
  `spa_orthant2`, `spa_orthant`, `spa_mv`, `spa_tri`, `spa_ratio_pdf`, `qf_Kmulti`, the
  noncentral chi-squared and F routines, ...), which take the derivatives from a function
  `Kfun(nu, t)` and can be used directly when closed-form derivatives are available;
* `tests/test_spx.m`: checks against closed forms and against the 409 reference values shared
  by the Julia and Python packages (`julia_reference.csv`, made by `julia_reference.jl` from
  `test/reference_values.jl` of the Julia package); the expansions agree to about `1e-13`
  relative (at most `1e-11`), and those for several ratios are also checked against closed forms;
  the Studentized-mean functions are checked as in the Julia and Python packages, against the
  noncentral t and against the reference values of the Dickey-Fuller t-ratio
  (`tests/dickey_fuller_cgf.m`, a test fixture);
* `examples/demo_spx.m`: examples;
* `doc/`: the manual (`manual.pdf`, source `manual.tex`).

## Differences from the Julia and Python packages

The same expansions are in the Julia package
[SaddlepointExpansions.jl](https://github.com/s-broda/SaddlepointExpansions.jl) and the Python
package [saddlepoint-expansions](https://github.com/s-broda/saddlepoint-expansions)
(`Pkg.add("SaddlepointExpansions")` and `pip install saddlepoint-expansions`). The MATLAB
computations are in double precision; the Julia package also runs in `BigFloat`, and repeats the
density of a Studentized mean in `BigFloat` where its terms cancel strongly (here, as in the Python
package, `r.status` then reports `'coefficients inaccurate'`). For variable precision use the
engine directly with a `Kfun` that accepts `vpa` arguments.
